09 — EXAMPLE

评分对比实例

Shampoo 批次 Target = 2.2，两个系统均合法 — 谁胜出？

GSS1 + GSS2

(0, 1, 0, 0, 2.2, "GSS12")

gss12_small = 1 — 小批惩罚 ❌

GSS3

(0, 0, 1, 0, 0.0, "GSS3")

gss12_small = 0 — 无惩罚 ✓

结论

第 2 位 gss12_small：GSS3 (0) < GSS12 (1)
→ GSS3 胜出，2.2 小批由小批专用系统承接

10 — OPTIMIZATION

二次合并 & 超限再平衡

Second Pass Merge

首轮分配后，仍可升级为更大批次的合并机会

触发条件：
· 同系统 + 同 WIP + 同 Type
· 至少一侧为欠装单批 (Load/Target < 0.90)
· 合并后命中合法目标
· 合并后不恶化超限
示例：3.538 + 13.821 → 合并为 Target 17.6

Overflow Rebalance

当某系统超限时，尝试借用其他系统产能

典型场景：
· GSS3 超限 → 借 GSS1+GSS2 产能
· 确保班次统计口径一致
· 重建产能占用记录
执行顺序：搭批 → 合并 → 再平衡 → 报表
