07 · Tolerance

双层容差控制

Preferred（优选）+ Hard（硬边界）分开管理

MOQPreferredHard
1.1± 0.05± 0.20
2.2± 0.08± 0.30
4.4± 0.12± 0.30

多倍 MOQ 容差放大：
每 +1× 4.4 → Preferred +0.06, Hard +0.20

IN_PREFERRED ✓

命中优选区间 — 最理想状态

IN_HARD_ONLY ⚠

未入优选区，但在硬边界内 — 可接受

OUTSIDE_HARD ✗

超出硬边界 — 不允许

08 · Algorithm

搭批算法流程

1 按 WIP Code 分组
2 小单优先组合 (MSU ≤ 3.0)
3 目标从大到小降序尝试
4 先同日 → 再跨日
5 规则合法才进入系统比较

小单组合策略

_build_combo_for_target

· 2 单 → 凑 4.4 或 2.2
· 3 单 → 凑 4.4
· 单单直接成批（如 2.18 → 2.2）

10 · Optimization

二次合并 & 超限再平衡

Second Pass Merge

首轮分配后，仍可升级为更大批次

· 同系统 + 同 WIP + 同 Type
· 至少一侧欠装 (Load/Target < 0.90)
· 合并后命中合法目标
· 不恶化超限

示例：3.538 + 13.821 → Target 17.6

Overflow Rebalance

某系统超限时借用其他系统产能

· GSS3 超限 → 借 GSS1+GSS2
· 确保班次统计口径一致
· 重建产能占用记录

顺序：搭批 → 合并 → 再平衡 → 报表
